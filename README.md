# CozyCubes

A clean, fast speedsolving timer for the Rubik's Cube.

## Planned features

- Spacebar-driven timer (hold to arm, release to start, tap to stop)
- Session history with best/average-of-5/average-of-12 stats
- Scramble generator per WCA-style notation
- Local persistence of solve times, no account required

## Stack

React + Tailwind CSS (front-end setup pending — see `public/` and `src/` for
the current folder scaffolding).

## Status

Work in progress. Folder structure and HTML boilerplate are in place; the
React/Tailwind build setup and timer logic are still to come.
